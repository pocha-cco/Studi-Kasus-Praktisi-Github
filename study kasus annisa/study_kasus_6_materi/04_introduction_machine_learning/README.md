# Study Kasus 4 — Introduction to Machine Learning

## Deskripsi
Klasifikasi kualitas bunga Iris menggunakan model Decision Tree dan evaluasi akurasi.

## Cara menjalankan
1. Pastikan Python 3.10 atau lebih baru terpasang.
2. Buka terminal pada folder proyek ini.
3. Instal dependensi: `pip install -r requirements.txt`
4. Jalankan perintah yang sesuai:
   - Proyek biasa: `python main.py`
   - Dashboard HCI: `streamlit run app.py`

## Struktur
- `main.py` / `app.py`: kode utama.
- `data/`: dataset contoh.
- `output/`: keluaran program (dibuat saat program dijalankan).

## Catatan akademik
Dataset dalam proyek ini merupakan data contoh/sintetis untuk demonstrasi. Interpretasikan hasil sesuai batasan studi kasus dan jangan menganggap hasil demo sebagai bukti dunia nyata.
